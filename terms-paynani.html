2. Descripción del servicio

Paynani API REST Client es una herramienta destinada a desarrolladores, estudiantes y profesionales de tecnología para realizar pruebas y consumir servicios web mediante solicitudes HTTP y HTTPS.

Entre las funcionalidades disponibles se encuentran:

  • GET
  • POST
  • PUT
  • PATCH
  • DELETE
  • Configuración de Headers
  • Parámetros de consulta (Query Parameters)
  • Cuerpo de la solicitud (Request Body)
  • Visualización de respuestas
  • Gestión local de colecciones y configuraciones (cuando el usuario decida guardarlas)

La aplicación funciona exclusivamente como un cliente REST y no actúa como intermediario entre el usuario y los servidores con los que este decide comunicarse.

Todas las solicitudes HTTP o HTTPS realizadas desde la aplicación son configuradas y enviadas exclusivamente por el usuario.

Desarrollos CesarGunn:

Toda comunicación ocurre directamente entre el dispositivo del usuario y el servidor de destino.
